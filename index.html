About

Small team.
Big ideas.

UltraSonic Technologies is a technology organization focused on building useful and creative software.

We explore programming languages, development tools, game technology, user interfaces and other areas where software can become simpler, faster and more expressive.

The goal is straightforward: build technology that developers actually enjoy using.
